Detailed Description

Foundational type system for the RISC-V simulator.

Fixed-width integer aliases, address/cycle types, exception hierarchy, and bit-manipulation utilities used throughout the simulator. All bit-manipulation helpers are constexpr and noexcept for use in hot decode/execute paths.

Host requirement
A little-endian host is required to match the RISC-V base ISA. This is enforced at compile time via static_assert.

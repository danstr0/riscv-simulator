Detailed Description

Stateless two-pass RISC-V assembler.

Assembles a text source string into a byte vector of machine code suitable for loading directly into the simulator memory.

Assembly Syntax

Labels

A label is an identifier followed by a colon at the start of a line. Labels may optionally be followed by an instruction on the same line.

loop:
start: addi t0, t0, 1

Comments

Everything after:

  • #,
  • ;,
  • or // is ignored.

Registers

  • Integer: x0-x31 or ABI names (zero, ra, sp, gp, tp, t0-t6, s0-s11, a0-a7, fp).
  • Vector: v0-v31.
  • CSR: named (mstatus, mie, mtvec, mepc, mcause, mip) or hexadecimal (0x300). Range 0x000-0xFFF.

Numeric Literals

Decimal (42), hexadecimal (0xFF), or negative (-10, -0x10).

Encoding

The assembler is two-pass: pass 1 collects labels and computes instruction sizes, and pass 2 encodes. All instructions emit 4 bytes except li with an immediate outside [-2048, 2047], which emits 8 (lui + addi).

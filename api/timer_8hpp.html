Detailed Description

Core Local Interruptor (CLINT) machine timer.

Maintains a 64-bit real-time counter (mtime) and a 64-bit compare register (mtimecmp). Asserts a level-triggered Machine Timer Interrupt whenever mtime ≥ mtimecmp.

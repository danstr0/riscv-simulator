Detailed Description

Simplified Platform-Level Interrupt Controller (PLIC) for RISC-V.

Models a single-hart PLIC conforming to the RISC-V PLIC Specification v1.0.0, supporting up to 31 interrupt sources (source 0 is reserved as "no interrupt").

Interrupt lifecycle
A device asserts an interrupt via set_pending(). If the source is enabled and its priority exceeds the threshold, the notify callback fires. The CPU claims the interrupt (returning the highest-priority pending ID and clearing the pending bit), services it, then writes the ID back to complete.

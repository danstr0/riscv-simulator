Detailed Description

Multi-level cache chain backed by a main memory.

All accesses enter through L1. On a miss, L1's next level (L2) is consulted, and so on. Implements the Memory interface for drop-in use.

Latency model
Returned latency is the sum of hit_latency at every level hit, plus miss_penalty at every level that missed.

Detailed Description

Memory subsystem and bus routing for the RISC-V simulator.

Defines a unified memory interface allowing the CPU to interact with RAM, ROM, and MMIO devices transparently through a common bus.

Address translation
The MMIOBus routes requests using absolute addresses, then subtracts the region's base to present each device with a zero-based offset.
Latency modeling
MemoryResult includes a cycles field for cycle-accurate timing and cache-miss penalty injection.

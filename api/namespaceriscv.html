template<unsigned B>
constexpr i32 riscv::sign_extend ( u32  value)
constexprnoexcept

Sign-extend a B-bit value to a full i32.

Masks to B bits, then replicates the sign bit (bit B-1) into the upper 32-B bits. Used extensively in immediate extraction during instruction decoding.

Template Parameters
BNumber of significant bits (1 ≤ B ≤ 32).
Parameters
valueRaw bitfield extracted from the instruction word.

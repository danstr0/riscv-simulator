Detailed Description

Instruction decoder for the RISC-V simulator.

Decodes 32-bit instruction words into a structured representation covering RV32IMA and a subset of RVV.

Decode Process
Bits [6:0] select the major opcode, which dispatches to a format-aware helper that extracts register fields, reconstructs the sign-extended immediate, and maps funct3 / funct7 to a concrete Op tag.
See also
RISC-V Unprivileged ISA Specification, Sections 2.1, 6.1.1, 12.1, 13.1, 30.1.

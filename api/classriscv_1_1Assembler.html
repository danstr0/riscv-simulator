Detailed Description

Stateless two-pass RISC-V assembler.

All parsing and encoding helpers are static. The public entry points (assemble(), assemble_lines()) are const and produce an AsmResult containing either the assembled byte stream or a list of errors.

Parse helper convention
All parse_* methods return true on success (writing the result to an output parameter) and false on failure (leaving the output parameter unmodified).

Encode one parsed instruction into machine code words.

Returns
One or two 32-bit words on success, or an error message string.

Encoding is organized by instruction category, in this order: RV32I pseudo-ops, R-type ALU, I-type ALU, LUI/AUIPC, loads, stores, branches, JAL/JALR, system, CSR, A extension, V extension.

Detailed Description

Synchronous multi-Core SoC simulation environment.

Models a cycle-synchronous shared-memory multiprocessor with directory-based coherence, a shared cache hierarchy, and memory-mapped I/O devices (PLIC, Timer, NIC).

Memory layout
Device MMIO addresses are placed immediately above main memory:
  • device_base = align_up(mem_size, 0x1000)
  • PLIC: device_base + 0x0000
  • Timer: device_base + 0x1000
  • NIC: device_base + 0x2000
Interrupt delivery
External devices signal the PLIC, which performs priority arbitration and asserts MEIP in the target core's mip register.
